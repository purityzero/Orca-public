1. 한 줄 요약 / 핵심 재미

"수영으로 하는 마리오카트." 3D 3인칭 시점, 레인이 나뉜 수영장을 달리며 아이템을 먹고 던지고, 스타트·턴 타이밍을 정확히 맞춰 부스터를 터뜨려 1등을 노린다.

레이싱 게임과 다른 이 게임만의 축

턴이 곧 코너다

카트의 드리프트 = 수영의 플립턴. 50m마다 벽을 차는 순간이 순위가 뒤집히는 지점.

스태미나

카트는 연료가 없지만 수영은 지친다. 스퍼트를 언제 쓸지가 판단 요소.

물 = 지형

파도, 해류, 다른 선수가 만든 물살(드래프팅). 코스가 매 순간 조금씩 변한다.

귀여움

뚱뚱보가 물보라를 일으키며 1등하는 그림. 캐주얼 코미디 톤이 아트의 기준선.

드래프팅 (제안) 앞 선수 바로 뒤에 붙으면 물살에 빨려 저항이 줄어 서서히 가속된다. 1등이 계속 1등하기 어렵게 만들고, 아이템 밸런싱 없이도 순위가 붙게 하는 장치. 마리오카트의 슬립스트림과 같은 역할이며 수영에서는 실제로 존재하는 현상이라 설명이 필요 없다.

2. 코어 루프

[레이스 90~120초] ├─ 스타트 다이빙 타이밍 → 초반 부스터 ├─ 레인 이동 / 아이템 획득 / 공격 · 방어 ├─ 턴 타이밍 (25m 또는 50m마다) → 부스터 └─ 골인 순위 확정 ↓ [보상] 코인 + 캐릭터 경험치 + (확률) 장비 조각 ↓ [성장] 코인으로 능력치 강화 / 장비 구매 · 강화 · 세트 완성 ↓ [해금] 새 캐릭터 · 새 경기장 · 상위 리그 ↓ 다시 레이스 (더 빠른 상대와)

한 판이 짧아야 "한 판만 더"가 성립한다. 목표 1레이스 = 100초 내외(로딩·결과 제외). 100m(50m 풀 왕복) 기준.

3. 시점과 조작

3.1 시점 — 네, 3D여야 합니다

말씀하신 "캐릭터 살짝 뒤" 시점은 3인칭 추격 카메라(third-person chase cam)이고, 이건 3D 공간에서만 성립합니다. 다만 게임 자체는 3D여도 플레이는 레인 위 좌우 이동으로 제한되므로(온레일에 가까움) 물리·AI 난이도는 완전 자유 3D 레이싱보다 훨씬 낮습니다.

항목값비고
카메라 위치캐릭터 뒤 3.5m, 위 1.6m, 살짝 내려다봄(약 -8°)수치는 실제 붙여보고 조정
속도 연출부스터 시 FOV 60→75, 화면 가장자리 물보라, 모션블러 약하게속도감의 8할은 FOV와 이펙트
수면카메라가 수면에 반쯤 걸침 — 물 위/아래가 화면에 같이 보임수영 게임 정체성. 물속 굴절 셰이더 필요
턴 연출턴 순간 카메라 짧게 당겼다 밀기 + 화면 흔들림Perfect일 때만 강하게

3.2 조작 (모바일 기준 / PC 병행)

입력동작
좌우 스와이프 / ←→레인 변경 (1레인씩, 이동 중 잠깐 느려짐)
화면 탭 / Space타이밍 판정 입력 (스타트, 턴, 호흡 QTE)
아이템 버튼 / Ctrl아이템 사용 (길게 눌러 뒤로 발사)
스퍼트 버튼 / Shift스태미나 소모 가속. 누르는 동안 지속
결정 필요 — 전진 방식 2안 A안 (추천): 자동 전진. 캐릭터는 알아서 헤엄치고, 플레이어는 레인·타이밍·아이템·스퍼트만 관리. 마리오카트에 가깝고 모바일에서 손이 편하다. 한 손 플레이 가능.
B안: 리듬 입력 전진. 좌우 번갈아 탭해 스트로크를 만들고, 리듬이 맞으면 속도 유지. 수영 느낌은 훨씬 강하지만 100초 내내 연타라 피로하고, 아이템 조작과 손가락이 충돌한다.
→ A안을 기본으로 가되, B안의 리듬감은 "스퍼트 구간에서만" 부분 도입하는 절충(스퍼트 중에만 리듬 링이 떠서 맞추면 추가 가속)을 권합니다.

4. 리듬 · 부스터 (스타트 / 턴)

이 게임의 실력 축은 타이밍 3종이다. 전부 동일한 판정 UI(좁아지는 링 또는 움직이는 게이지)를 쓰되, 보상 크기가 다르다.

타이밍발생PerfectGoodMiss
스타트 다이빙레이스 시작 1회속도 +40%, 3초+20%, 2초부정출발 → 0.8초 정지
턴 (벽 차기)25m마다 (100m 코스 = 3회)속도 +35%, 2.5초 + 스태미나 소량 회복+15%, 1.5초가속 없음 + 0.3초 감속
호흡 선택일정 주기 (스태미나 낮을 때만)스태미나 회복 +30%+15%회복 없음, 잠깐 감속
판정 창 Perfect ±90ms / Good ±200ms부터 시작(체감 보고 조정).
최초안은 ±60ms였으나, 모바일은 터치 샘플링·디스플레이 지연만으로 기기 간 30~80ms가 갈린다. ±60ms에서는 실력이 아니라 기기 성능이 판정을 가른다. 리듬 전문 게임이 아니라 캐주얼 레이싱이므로 창을 넓게 잡고 시작한다.
운 스탯이 높으면 판정 창이 넓어지는 방식은 쓰지 않는다 — 실력 축과 성장 축을 섞으면 "돈으로 잘하는 게임"이 된다. 성장은 보상 크기만 키운다(같은 Perfect라도 부스터 스탯이 높으면 더 빠름).
입력 지연 보정 옵션에 타이밍 오프셋 조정(-100ms ~ +100ms)을 반드시 넣는다. 리듬 요소가 있는 게임에서 이게 없으면 특정 기기 사용자는 영구히 불리하다. 초회 실행 시 자동 캘리브레이션 3회 탭으로 기본값을 잡아준다.
주의 턴이 3회뿐이면 타이밍 재미가 희소하다. 반대로 25m마다는 화면이 정신없을 수 있다. 50m 풀 왕복(턴 1회) / 25m 풀 4번 왕복(턴 3회) 중 어느 쪽을 기본 코스로 할지 초기에 프로토타입으로 확인할 것.

5. 트랙 구조 · 수심 · 영법

  • 레인 수: 8 = 참가 인원과 동일. 실제 수영 경기와 같은 구조이며, "5레인에 8명"은 겹침 처리 규칙을 억지로 만들게 되므로 채택하지 않는다.
  • 레인 변경은 1레인 단위, 변경 중 속도 5% 감소 (무작정 지그재그 방지)
  • 레인 위 배치물: 아이템 박스 / 부스터 패드(물살) / 장애물 / 지름길 게이트
  • 레인 로프(구분선)에 부딪히면 감속 — 레인 변경 타이밍도 실력 요소

5.1 충돌 · 추월 우선순위

같은 레인에 두 명이 겹치는 순간의 규칙. 이게 없으면 접전이 매번 "누가 이겼는지 모르겠는" 상황이 된다.

상황처리
같은 레인 · 뒷사람이 더 빠름드래프팅 구간 → 접촉 없이 통과. 추월 자체는 항상 가능
레인 변경 중 몸이 겹침먼저 그 레인에 있던 쪽이 우선. 들어오는 쪽이 감속(-8%)
양쪽이 동시에 같은 레인으로둘 다 원래 레인으로 튕김, 둘 다 감속. 요행 없음
스턴 중인 캐릭터와 접촉스턴 대상은 충돌 판정에서 제외(통과). 사고 연쇄를 막는다
아이템 피격 우선순위무적 > 거품막 > 스턴 > 감속. 상위가 있으면 하위는 아예 적용되지 않음
레인 간 유불리는 없다 직선 코스에서는 안/바깥 레인의 거리 차이가 없다. 따라서 배치물을 "불리한 레인 보상"으로 쓰지 않는다 — 배치물의 목적은 레인마다 다른 선택지를 주는 것(A레인은 부스터 패드가 있지만 장애물도 있음, B레인은 안전하지만 밋밋함)이다.
배치물효과배치 원칙
아이템 박스아이템 1개 획득레인마다 같은 거리에 배치(공평). 1구간당 1개
부스터 패드(해류)1.5초 가속매 구간 일부 레인에만 배치. 어느 레인이 좋은지가 구간마다 바뀌어 레인 이동 동기를 만듦
장애물(부표/얼음/해파리)접촉 시 감속 또는 짧은 스턴부스터 패드 옆에 배치해 "먹으려면 위험" 구조
지름길 게이트수중 통로 등 짧은 우회로. 진입 조건 있음경기장별 1~2개. 스퍼트 or Perfect턴 직후에만 진입 가능

5.2 수심 레이어 — 수면 / 수중 신규

왜 필요한가 좌우 레인 이동만 있으면 이건 "물에서 하는 자동차 게임"이다. 물의 정체성은 위아래로도 움직일 수 있다는 데 있다. 레인(좌우) × 수심(상하)의 2축이 되면, 같은 코스에서 훨씬 많은 판단이 생긴다.
레이어속도장점대가
수면 (기본)100%스태미나 정상 회복, 시야 넓음, 아이템 박스 대부분이 여기모든 공격의 표적
수중 (잠수)105%날아오는 아이템 회피, 해류 지대 이용, 수중 지름길 진입산소 게이지 감소(약 4초 한계), 시야 흐림, 아이템 획득 불가
  • 조작: 아래 스와이프 = 잠수 / 위 스와이프 = 부상. 전환에 0.4초 소요(즉시 회피는 불가 — 미리 읽어야 함)
  • 산소가 0이 되면 강제 부상 + 2초간 감속. 체력 스탯이 산소 지속시간에도 관여한다
  • 턴 직후 돌핀킥 구간: Perfect 턴을 하면 잠수 상태로 시작하며 이 구간만 속도 120%. 실제 수영 전술 그대로다

5.3 영법 전환 검토

자유형만 있으면 "속도 하나"뿐이지만, 영법이 여러 개면 지금 무엇이 부족한가를 매 순간 판단하게 된다.

영법속도스태미나쓰는 순간
자유형100%보통 소모기본. 대부분의 구간
접영115%급격히 소모골인 직전, 추월 승부처
평영88%회복순위가 안정적일 때 숨 고르기, 파도 대기
배영 선택95%보통뒤를 볼 수 있음 — 뒤에서 오는 아이템 확인 가능
도입 판단 이건 재미를 크게 키울 수도, 조작을 감당 못 하게 만들 수도 있다. 레인 이동 + 수심 + 타이밍 + 아이템 + 스퍼트에 영법까지 얹으면 모바일 한 손 조작으로는 불가능하다.
→ 수심 레이어를 먼저 넣고 프로토타입에서 조작 부하를 재본 뒤 영법 도입을 결정한다. 둘 다 넣는다면 영법은 자동 전환(스태미나 낮으면 알아서 평영)으로 단순화하는 안도 있다.

6.1 획득 확률

순위가 낮을수록 강한 아이템이 뜨는 러버밴딩 테이블을 기본으로 하고, 운 스탯이 이 테이블을 상위 등급 쪽으로 밀어준다.

순위 구간하급중급상급
1~2위70%28%2%
3~5위40%45%15%
6~8위15%45%40%

확정 2026-08-31 운은 상급 확률을 올리지 않는다. 대신 두 가지만 건드린다:

  • 중급 이상 확률 += 운스탯 × 0.4%p (상한 +10%p) — 하급에서 차감. 즉 운이 높으면 "꽝이 덜 뜬다". "대박이 더 뜬다"가 아니다.
  • 아이템 박스 쿨다운 -= 운스탯 × 0.5% (상한 -12%) — 같은 코스에서 아이템을 조금 더 자주 먹는다

수치는 전부 CSV 테이블로 관리하고 코드에 박지 않는다.

왜 상급 확률을 안 올리나 아이템 레이싱에서 상급 아이템 1개의 가치는 스피드 몇 %보다 훨씬 크다. 운이 상급 확률을 직접 올리면 운 = 유일한 정답 스탯이 되어 다른 세 스탯이 죽는다. "꽝을 줄이는" 방향은 체감은 확실하되 상한이 명확해서 폭주하지 않는다.
남은 위험 그래도 초롱의 고유 특성 "아이템 2개 획득"은 여전히 세다 — 사실상 상급 확률을 두 번 굴리는 것과 같다. 발동 확률을 5% 이하로 잡고, 1,000회 시뮬레이션으로 캐릭터별 승률을 실측해 45~55% 범위를 벗어나면 조정한다.

8.1 강화

  • 스탯별 레벨 1~20, 레벨당 스탯 +1. 코인으로 강화.
  • 특화 스탯은 상한 25, 비특화는 15까지 — 캐릭터 개성이 성장 후에도 남게 한다.
  • 강화 비용 cost = 120 × level^1.6 (Lv1→2 = 120, Lv10→11 ≈ 4,780, Lv19→20 ≈ 14,600)
  • 캐릭터 레벨은 레이스 경험치로 오르고, 오를 때마다 강화 가능 상한이 열린다(코인만으로 순식간에 만렙 되는 걸 막는 게이트).
  • 강화는 실패 없음. 캐주얼 레이싱에 확률 강화는 이탈 요인.

핵심: 성장은 싱글과 일반전에서 보상하고, 랭킹전에서는 실력만 남긴다. 이러면 과금이 "더 강해지는" 게 아니라 "더 빨리 컨텐츠를 여는" 것이 되어 P2W 비난을 피한다. 랭킹전에서 세트 효과를 남기는 건, 그게 수치가 아니라 플레이 스타일 선택이기 때문이다.

12.2 개발 단계와 MVP 범위

이 문서의 대부분은 아직 만들지 않는다. 아래 태그로 단계를 구분한다. MVP가 아닌 것은 설계만 해두고 손대지 않는다 — 지우지 않는 이유는 나중에 같은 고민을 다시 하지 않기 위해서다.
단계목표포함제외
P0
MVP		 "이게 재밌나?"
단 하나만 확인		 경기장 1개(시립 수영장), 캐릭터 1명(태오), 헤엄 + 스타트 + 턴 + 부스터, 수심 레이어, AI 없이 혼자 아이템·성장·경제·상점·다른 캐릭터 전부
P1경쟁의 재미 AI 7명, 아이템 3종(어뢰 / 거품막 / 돌고래 튜브), 순위·보상 화면 아이템 나머지 8종, 장비, 세트
P2계속할 이유 캐릭터 5종, 스탯 강화, 코인 경제, 아이템 전종 캐시 상점, 세트, 시즌

P0에서 재미가 안 나오면 P1 이후를 만들어도 안 난다. 아이템과 성장은 이미 재미있는 것을 증폭할 뿐, 재미없는 것을 재미있게 만들지 못한다. P0 판정 기준을 미리 정해둔다: "아이템도 상대도 없이 혼자 3분 이상 반복하게 되는가." 안 되면 조작이나 코스 설계를 갈아엎고, 다음 단계로 넘어가지 않는다.

13. 기술 전제

  • 3D 필수 — 3인칭 추격 시점 때문. 단, 이동은 레인 제한이라 물리는 단순화 가능(캐릭터는 스플라인 위를 진행, 좌우 오프셋만 관리).
  • 물 표현이 이 게임의 인상을 좌우 — 수면 셰이더 + 물보라 파티클 + 물속 굴절이 최소 요구. 모바일 타깃이면 여기서 성능이 먼저 깎인다.
  • 캐릭터 스윔 애니메이션은 자유형 루프 1개 + 턴 + 다이빙 + 피격이 최소 세트. 5종 × 4모션.
  • 모든 밸런스 수치(스탯 계수, 아이템 확률, 강화 비용, 보상)는 CSV 테이블로. 코드 상수 금지.
  • 타깃 플랫폼 결정 필요 — 모바일 우선인지 PC 우선인지에 따라 조작·아트 예산이 크게 갈린다.

  • 유저층 — 캐주얼 레이싱의 주 확장 대상은 여성·저연령층인데, 이 방향은 그 층을 밀어낸다
