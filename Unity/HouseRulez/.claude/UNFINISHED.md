# 미완료 작업

## 2026-08-28-3 — 종족별 업그레이드 시스템

기획 초안 완료, 구현 미착수. `design/upgrade-system.md`에 타이틀의 종족별 영구 메타 업그레이드, 런 내부 흡수 승급, 각인·코어를 서로 다른 시스템으로 분리해 기록했다. 사용자 최신 요구에 따라 공용 구현 위에서 `HouseKey`별 화면·저장·진행을 독립시킨다.

구현 전 우선 결정할 항목은 영구 메타 범위, 트리 형태, 재화/획득 경로, 종족별 노드 효과와 수치다. 런 승급은 자동/선택 방식, 각인 계승, 유닛 사망 및 승급 후 위치 규칙을 먼저 확정해야 한다. 기존 GDD의 "초기 빌드 영구 강화 트리 제외" 문구는 영구 메타를 진행하기로 확정할 경우 개정한다.

## 2026-08-28-2 — 설정/종족 선택 팝업 UITable 전환

완료. `UISetting`과 `UIHouseSelect`를 `UITable`/`UIManager` 경로로 등록하고, BGM·SFX 볼륨 옵션을 연결했다. GeometryDefender 음원 파일은 이식하지 않았다. Play Mode 표시·상호작용과 컴파일/테이블 검증을 완료했다.
