# Judge / JudgeResult / SummonSlot

관련 클래스: JudgeTable, UnitGradeTable, HouseTable, UIHouseSlotMachine

경로: `Assets/Scripts/InGame/Judge/Judge.cs`, `JudgeResult.cs`

3×3 스핀 결과를 종족 문법으로 읽어 **전력**을 내고, 그 전력을 **소환 유닛(칸 + 등급)**으로 바꾼다.

## 2026-08-30-0 — 신규 (4종족)

### 판정 알고리즘

GDD(`Assets/Design/reel_of_four_houses_GDD.html`)의 `judge()`를 옮겼다. 8라인(가로3·세로3·대각2)을 종족별 문법으로 읽는다.

| 종족 | 문법 | 패턴 | 계수 |
|---|---|---|---|
| chess | 동일성 | 라인 3개 같음 / 2개 같음 | 8.0 / 1.3 |
| janggi | 위치 관계 | A–B–A / 가운데가 包 / 끝만 겹침 | 3.8 / +3.8 / 0.95 |
| poker | 순서 | 트리플 / 스트레이트 / 페어 | 40 / 11 / 1 |
| hwatu | 전역 짝(섯다) | 세로 3열 중 **최고 하나만** 채택 | 족보값 × 0.2055 |

계수는 [[JudgeTable]]에 있다. 섯다 족보값(땡 90/70/…, 광땡 220/170/140)은 수백 년 된 **규칙**이라 코드 상수로 두고, 조정하는 건 `HwatuScale` 하나다.

**GDD와 의도적으로 다른 두 곳**
1. **화투 입력** — GDD는 `demoMonths[grid[i] % 6]`으로 6개월만 쓰는 데모용 축약이다. 여기서는 심볼 인덱스+1을 월로 읽어 12개월 풀 전체를 쓴다.
2. **소환 환산** — GDD 데모는 전력÷3을 표시만 한다. 실제 규칙은 아래.

`장기 包`는 심볼 인덱스 3이다. 스프라이트가 이름 오름차순(cha·jol·ma·po·sa·sang·wang)으로 로드되므로 그렇고, **추측이 아니라 실제 폴더로 확인했다.**

### 전력 → 소환

```
1) 전력만큼 1성 유닛을 놓는다. 자리는 판정에 걸린 칸(ListHitCell)부터, 모자라면 남은 칸 순서대로
2) 9칸을 다 쓰고도 전력이 남으면 등급을 올려 흡수한다 (1성 → 2성 → 3성)
   승격 비용 = 배수 차이. 1성→2성 = 2.6−1.0 = 1.6, 2성→3성 = 7.0−2.6 = 4.4
   남은 전력이 비용의 절반 이상이면 승격 (반올림과 같은 기준)
```

**걸린 칸만으로는 자리가 안 채워진다.** 실측 평균 hit 칸이 체스 0.65 · 장기 2.62 · 포커 0.83 · 화투 2.04로 소환 수보다 훨씬 적다. "릴 3×3이 전장 3×3에 1:1"만으로는 배치가 정해지지 않아 이 규칙을 따로 뒀다.

### 왜 등급으로 돌리나 — 상한 자르기가 밸런스를 깼다

처음엔 9칸을 넘으면 그냥 잘랐다. 그랬더니 GDD가 "평균은 붙이고 분산만 벌린다"로 설계한 것이 **정반대로** 나왔다.

| 방식 | 체스 | 장기 | 포커 | 화투 | 종족 간 차이 |
|---|---|---|---|---|---|
| 상한 자르기 | 5.37 | 5.70 | **3.61** | 3.92 | **2.09** |
| 등급 전환 | 6.17 | 6.46 | 6.39 | 6.22 | **0.29** |

분산이 큰 포커·화투가 상한에서 가장 많이 깎였기 때문이다. 등급으로 돌리면 그 종족이 **더 센 유닛**으로 보상받는다 — 포커 3성 비율 11.1% vs 체스 1.7%.

### 알려진 한계 — 63이 절대 상한

9칸 전부 3성이 최대라 **배치 가능한 전력은 63**이다. 그 위는 버려진다.

```
입력 4,9,4,4,4,10,4,4,4 → 트리플 4개 → Power 164, placedPower 63, 101 버림
```

포커 30만 회 중 오차 10 초과 **326회(0.1%)**. 드물지만 **가장 큰 판정에서만** 발생한다. 프리즘(×18.0)을 상한에 넣으면 해소되나, 프리즘은 심판 웨이브 클리어 조건과 전장 2칸 점유가 붙은 별개 기능이라 끌어오지 않았다.

또한 승격 기준이 "비용의 절반"이라 배치 전력이 Power보다 평균 0.05~0.19 높다(장기 6.46 · 포커 6.39로 목표 6.1~6.3을 살짝 초과). **전투가 붙어 실제 클리어율을 볼 수 있을 때 조정한다.**
