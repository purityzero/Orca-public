# Runbook

**성공한 절차와 값비싸게 알아낸 사실**을 재현 가능한 형태로 적어둔 곳이다.

## 무엇을 넣는가

- **2번 이상 실패한 뒤 알아낸 것** — 한 번의 실수는 여기 안 온다
- **디버그로 원인을 특정한 것** — "그때 왜 그랬는지"를 다시 파헤치지 않게
- **문서에 적힌 사실이 틀렸던 것** — 무엇이 어떻게 틀렸는지까지

## 무엇을 넣지 않는가

- 코드를 읽으면 아는 것 (구조, 호출 관계)
- git 이력이 답해주는 것 (언제 무엇이 바뀌었나)
- 한 프로젝트에서만 통하는 고유명사 — 그건 그 프로젝트의 `.claude/class/`·`.claude/prefab/`으로

## ⚠️ 자동 로드하지 않는다

이 폴더는 **매 세션 주입되지 않는다.** 주입되는 문서가 이미 4만 자에 달해, 런북까지 얹으면
정작 중요한 규칙이 파묻히고 첫 응답 전에 컨텍스트를 먹는다. 작업을 시작할 때 **해당 주제만 골라 읽는다.**

2026-09-11에 상시 주입이던 `PREFAB.MD`와 `CLAUDE.md`의 상황 한정 절들을 여기로 내렸다
(자동 주입 55,256자 → 36,069자).

같은 이유로 `.claude/rules/`에는 절대 두지 않는다(그 폴더는 자동 로드된다).

## 승격 사다리

런북은 사다리의 첫 칸이다. 같은 실수가 반복되면 위로 올린다.

```
1회 실수      → 런북에 기록          (여기)
2회           → 메모리로 승격         (매 세션 주입)
3회           → 훅으로 강제           (안 지킬 수 없게)
```

각 항목에 **마지막으로 실제 적용한 날짜**를 적는다. 오래 안 쓰인 것은 아래로 강등하거나 지운다 —
안 그러면 런북이 또 하나의 읽히지 않는 문서가 된다.
