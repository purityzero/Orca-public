# Runbook — 씬·프리팹 편집

마지막 적용: 2026-09-10

## MCP 프리팹 스테이지는 저장하며 다른 것도 바꾼다

`open_prefab_stage` → 편집 → `save_prefab_stage`를 하면 유니티가 TMP 필드를 **정규화**해
의도하지 않은 변경이 함께 들어간다.

실측: 컴포넌트 **하나 추가**(약 14줄 기대) → 실제 diff **54줄**.

| 함께 바뀐 것 | 건수 | 성격 |
|---|---|---|
| `m_TextStyleHashCode: 0 → -1183493901` | 8 | 무해 (TMP가 채우는 "Normal" 해시) |
| `m_fontColor32.rgba` 캐시 갱신 | 5 | 무해 (float 색과 일치시키는 캐시) |
| **`m_sharedMaterial → {fileID: 0}`** | 1 | ❌ **되돌려야 함** |
| `UISetting`의 고아 직렬화 필드 삭제 | 5 | 무해 (C#에 없는 필드 정리) |

→ **저장 후 diff 크기를 먼저 확인한다.** 의도한 것보다 크면 한 줄씩 판정한다.

### `m_sharedMaterial`이 `{fileID: 0}`으로 떨어지는 이유

스테이지에서 TMP가 머티리얼 **인스턴스**(`... Material (Instance)`)를 들고 있으면
인스턴스는 직렬화되지 못해 0으로 저장된다. 렌더는 정상이라 **QA로는 안 잡힌다.**
에셋 머티리얼 fileID로 되돌려야 한다.

## 씬에 박히는 로컬 머티리얼

같은 원인으로 씬 안에 `--- !u!21 &<id>` `Material` 블록이 생긴다
(`LiberationSans SDF Material (Instance)` 등). 커밋본에 0개였는데 작업 후 2개가 생긴 사례가 있다.

→ 원본 에셋과 끊어져 있어 **나중에 그 머티리얼을 고쳐도 이 오브젝트만 안 따라온다.**
→ 검사: `grep -c "^--- !u!21 &" <씬파일>`

## 참조 fileID가 실재하는지 확인한다

프리팹 오버라이드가 **존재하지 않는 fileID를 가리키면 에러 없이 조용히 무시된다**(missing 표시도 없다).
텍스트나 이벤트가 안 먹히는데 원인을 못 찾겠으면 여기부터 의심한다.

```
grep -c "^--- !u!.* &<참조ID>$" <파일>     # 1 이어야 한다
```

## 좌표 겹침은 수치로 검증한다

눈으로 못 보는 편집에서는 **형제들의 구간을 계산해 겹침을 판정**한다.

- `left = x - pivot.x * width`, `right = left + width`
- **X와 Y가 모두 겹칠 때만 실제 겹침이다** — X만 겹치고 Y가 다르면 위아래로 나뉜 배치다
- 부모의 폭을 넘지 않는지도 함께 본다

실측 사례: 기존 버튼을 복제해 왼쪽에 뒀는데 그 자리에 라벨이 이미 있었다.
빈 구간이 172px뿐인데 복제본이 264px이라 **476~584가 겹쳤다.** 좌표 계산이 잡아냈다.

## YAML 값 기반 치환은 엉뚱한 블록을 친다

`m_SizeDelta: {x: 140, y: 40}` 같은 값은 파일 안에 **여러 번 나온다.**
값만 보고 치환하면 앞선 다른 RectTransform이 먼저 걸린다.

→ **오브젝트를 특정하는 값과 묶어서** 친다(예: 고유한 `m_AnchoredPosition`과 함께).
→ 치환 후 **실제로 그 오브젝트가 바뀌었는지** 다시 읽어 확인한다.

## 프리팹을 새로 만들 때

MCP 호출을 수십 번 하는 대신 `execute_code`로 **한 번에 구성**하고
`PrefabUtility.SaveAsPrefabAsset`으로 저장하면 오브젝트 7개 + 배선까지 1회에 끝난다.

저장 후 반드시 확인할 것:
1. 직렬화 참조가 **실재하는 fileID**를 가리키는가 (위 참조)
2. `m_fontAsset : m_sharedMaterial` 짝이 맞는가
3. **`.meta`가 함께 생성됐는가** — 빠뜨리면 체크아웃마다 GUID가 새로 생긴다

## 컴포넌트를 복제하면 리스너도 따라온다

기존 버튼을 `Instantiate`로 복제하면 `onClick`에 등록된 **영구 호출도 그대로 복사된다.**
복제본이 원본의 동작을 함께 실행하게 되므로 비워야 한다.

```csharp
button.onClick = new UnityEngine.UI.Button.ButtonClickedEvent();
```

로컬라이제이션 컴포넌트가 딸려 있으면 **키가 원본 것**이라 매 갱신에 덮어써진다 — 함께 정리한다.
